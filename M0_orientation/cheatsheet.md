# M0 — Cheatsheet


- MCP သည် **protocol တစ်ခု** — N × M integration ပြဿနာကို N + M အဖြစ် ပြောင်းသည်
- အခြေခံမှာ **JSON-RPC 2.0** — `tools/list`, `tools/call` ကဲ့သို့ method များ
- **Host / Client / Server** — Server က ကြေညာသည်၊ Model က ရွေးသည်၊ Host က ခွင့်ပြုသည်
- Server က ဖော်ထုတ်သည့် အရာ **၄ မျိုး** — tools, resources, prompts, elicitation
- **URI template** သည် resource မဟုတ် — template list တွင် သီးခြား ပါသည်
- `FastMCP` က protocol + schema + transport ကို ဖြေသည်; **လုံခြုံရေး၊ error ဒီဇိုင်း၊
  description အရည်အသွေး** ကို သင် တာဝန်ယူရမည်
