# M0 — Orientation: MCP ဆိုတာ ဘာလဲ

> **ကြာမြင့်ချိန်:** 1.5 နာရီ · **Phase:** Phase 1 — Foundations

## ဤသင်ခန်းစာတွင် ဘာရမည်လဲ

- MCP (Model Context Protocol) ဆိုတာ ဘာလဲဆိုတာကို အခြေခံကစပြီး နားလည်မည်
- MCP မရှိခင်ကြုံတွေ့ရတဲ့ ပြဿနာတွေကို မြင်နိုင်မည်
- Host / Client / Server ဆက်နွယ်မှုကို သိမြင်မည်
- Server က ဖော်ထုတ်ပေးသည့် အရာ ၄ မျိုးကို လေ့လာမည်
- `FastMCP` က ဘာကို လွယ်ကူစေသလဲဆိုတာကို နားလည်မည်
- LAB များဖြင့် JSON-RPC protocol ကို ကိုယ်တိုင် မြင်ရမည်

## သင်ခန်းစာများ

1. ပြဿနာကို အရင် မြင်ခြင်း — MCP မရှိခင် AI model တွေက tool တွေနဲ့ ချိတ်ဆက်ရတာ ဘာကြောင့် ခက်ခဲသလဲ
2. MCP ဆိုတာ တကယ် ဘာလဲ — protocol တစ်ခုအနေနဲ့ သတ်မှတ်ထားတဲ့ စည်းမျဉ်းတွေ
3. Host / Client / Server — MCP architecture ရဲ့ အစိတ်အပိုင်း သုံးခု
4. Server က ဖော်ထုတ်သည့် အရာ ၄ မျိုး — tools, resources, prompts, နဲ့ ကျန် surface များ
5. `FastMCP` က ဘာလုပ်ပေးသလဲ — Python နဲ့ MCP server ရေးရာမှာ လွယ်ကူစေတဲ့ layer

## လိုအပ်ချက်များ (Prerequisites)

- Python အခြေခံ နားလည်မှု (function, decorator, class အခြေခံလောက်)
- Terminal နဲ့ command လိုင်း အသုံးပြုနိုင်မှု
- JSON ဖိုင် format အကြောင်း အခြေခံ သိထားခြင်း
- ဤ module သည် course ရဲ့ ပထမဆုံး module ဖြစ်သောကြောင့် ယခင် module မလိုအပ်ပါ

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- MCP ကို စတင်လေ့လာမည့် ပထမဆုံး အချိန်
- AI model တွေကို tool တွေနဲ့ ချိတ်ဆက်ဖို့ စံနှုန်းတစ်ခု လိုချင်နေချိန်
- နောက် module ဖြစ်တဲ့ M1_python_env ကို မတက်ခင် အခြေခံသဘောတရား ချမှတ်ချင်ချိန်
